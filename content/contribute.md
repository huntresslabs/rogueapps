# Contribute to RogueApps

We'd love to hear your stories of RogueApps that you've seen!

If you want to contribute to the RogueApps project, please [open an Issue in the official GitHub repository.](https://github.com/huntresslabs/rogueapps/issues/new?assignees=&labels=new+rogueapp&projects=&template=custom.md&title=%5BNew+RogueApp%5D%3A+%28RogueApp+Name%29) Please follow the issue template and include details about the observed TTPs for the RogueApp. **Please do not submit any sensitive, private, or proprietary information.**
