# Contribute

The RogueApps project thrives on community contributions. If you've encountered an OAuth application being abused during an incident, we want to hear about it.

## How to Submit

1. [Open an issue](https://github.com/huntresslabs/rogueapps/issues/new?assignees=&labels=new+rogueapp&projects=&template=custom.md&title=%5BNew+RogueApp%5D%3A+%28RogueApp+Name%29) in the official GitHub repository
2. Follow the issue template and include the application's **App ID**, **permissions**, and **observed TTPs**
3. Add any relevant **references** (blog posts, advisories, write-ups)

> **Important:** Do not submit any sensitive, private, or proprietary information. Contributions should be based on publicly observable application metadata and documented tradecraft.
